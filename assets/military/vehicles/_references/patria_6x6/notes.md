# VEH-02 Patria 6x6 — reference notes

**Variant modelled:** Patria 6x6 (CAVS — Common Armoured Vehicle System, Finland / Latvia / Sweden / Germany / Denmark / Norway),
troop carrier hull, with the Kongsberg Protector RS4 remote weapon station used by the Norwegian command variant.
Camouflage: NATO three-colour (as Norwegian vehicles); Finnish vehicles carry the Finnish three-colour pattern.

## Recognition features modelled
Boat-shaped V-hull with a long wedge bow and folded trim vane, sponsons over the wheels, full-width cab with three armoured
windscreen panes and a door with window on each side (grab rail round the door), long-arm mirrors, recessed headlights in the bow
corners, smoke dischargers on the cab sides, roof hatches over the troop compartment, cab hatch, side stowage frames with snow
chains (Finnish photos), roof stowage box, rear troop door with vision block, rear lamps, towing eyes.

## Movable parts
Wheel_L1..R3 (spin; axles 1–2 steer), Door_FL / FR (cab doors), Door_Rear, Hatch_Cab, Hatch_L / R, RWS + RWS_Gun.

## Uncertainties
Patria publishes no axle-spacing drawing in the sources found; spacing and overhangs are photo estimates. The roof layout differs
between national variants (Finnish ring mount vs RWS); the Norwegian command variant's antenna fit is not documented.
