# SVD Dragunov - reference notes

Asset id: `weapon_svd`. Builder: `tools/blender/weapons/` (see the module docstring).

## Variant

Classic laminated-wood furniture with PSO-1 on the left-side rail.

## Dimensions

| Quantity | Value | Status |
|---|---|---|
| Overall length | 1,225 mm | published (Wikipedia) |
| Barrel | 620 mm | published |
| Calibre | 7.62x54 mmR | published |
| Scope height | sight line 0.152 m above the grip origin | estimated |

"Published" = taken from the cited public specification; "estimated" = measured on the reference photographs or chosen to fit them.

## Recognisable features modelled

Thumbhole skeleton stock with cheek rest, ventilated handguard, slotted flash hider, PSO-1 4x24, 10-round magazine.
